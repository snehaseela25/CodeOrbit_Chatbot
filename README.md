# Rule-Based Chatbot

## CodeOrbit Tech - Artificial Intelligence Internship

### Task 1: Rule-Based Chatbot

## Objective

The objective of this project is to develop a simple rule-based chatbot using Python. The chatbot responds to user inputs based on predefined rules and keywords.

## Features

- Responds to common greetings such as Hi, Hello, and Hey.
- Answers simple predefined questions.
- Recognizes keywords such as AI and Python.
- Provides a fallback response when the input is not recognized.
- Allows the user to exit using Bye, Goodbye, or Exit.
- Uses simple rule-based decision-making.

## Technology Used

- Python
- Visual Studio Code

## How It Works

The chatbot takes input from the user and converts it to lowercase.

It then checks the input against predefined rules using Python `if`, `elif`, and `else` statements.

If a matching rule or keyword is found, the chatbot returns the corresponding response.

If no rule matches the user's input, the chatbot displays a fallback response.
